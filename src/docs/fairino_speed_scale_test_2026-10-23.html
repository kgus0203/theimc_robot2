3. 속도 상향 효과

이동시간 단축

  • 0.20 / 0.05 → 0.40 / 0.10: 151.206초에서 111.163초로 40.043초, 약 26.5% 단축
  • 이전 0.15 / 0.03 → 0.40 / 0.10: 회차 평균 94.286초에서 55.582초로 약 41.0% 단축
  • 촬영 좌표 간 이동 대기시간이 줄어 한 번의 검사 작업을 더 빠르게 끝낼 수 있다.
  • 같은 운영시간 동안 수행할 수 있는 검사 횟수가 늘고, 로봇 이동 중 발생하는 비생산 시간이 감소한다.

가속도 증가의 효과

짧은 좌표 구간에서는 최고속도에 도달하기 전에 감속하는 경우가 많다. 따라서 속도만 높이는 것보다 가속도를 0.03 → 0.07 → 0.10으로 함께 올렸을 때 시간 단축 효과가 뚜렷했다. 0.40 / 0.10은 빠른 가감속으로 짧은 이동 구간에서도 설정 속도를 더 적극적으로 사용했다.
